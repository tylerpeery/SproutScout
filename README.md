# SproutScout

SproutScout is a simple, phone-friendly plant care app designed to help track outdoor plants, watering schedules, sunlight needs, care notes, and plant locations.

It is built as a free static web app that can be hosted with GitHub Pages and opened from a `github.io` link on any phone.

## Short Description

Scout your sprouts, track watering, and remember where every plant lives outside.

## Features

- Track individual plants by name, type, icon, and location
- Record sunlight needs such as full sun, part shade, or shade
- Set watering frequency and water amount notes
- See which plants are due or overdue for watering
- Mark plants as watered with one tap
- Place plant icons on a simple yard map
- Upload an outdoor photo and place plant pins directly on the image
- Export and import backups as JSON files
- Download calendar reminder files for watering schedules
- Use optional browser notifications when supported

## How It Works

SproutScout stores plant data directly in the browser using local storage. This keeps the app free and simple, with no backend server or paid database required.

Because the data is stored on the device/browser, use the backup feature before clearing browser data, switching phones, or changing browsers.

## Free Tools Used

- HTML
- CSS
- JavaScript
- GitHub Pages
- Browser local storage

No paid hosting, app store account, backend server, or database is required for the basic version.
